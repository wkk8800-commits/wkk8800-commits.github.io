01用途与当前状态

Gmail AI Assistant 是应用所有者本人使用的 Mac 本地邮件助手，不面向公众分发。它不是 Google 官方产品，也不代表 Google。

邮件处理功能目前仅完成离线开发及合成数据测试，尚未申请真实 Gmail 用户授权、读取真实账户资料或邮件。Telegram Bot 和 Bark 已选定、尚未接入本邮件助手；AI 服务和模型尚未确定，macOS 真实通知未启用。邮件发送入口持续关闭。

02计划处理的数据与权限

唯一计划申请的 Gmail OAuth 范围是 gmail.readonly。该范围可读取邮箱信息，不授予发送、修改、删除或归档邮件的权限。账户验证、有限邮件验证与持续同步是不同步骤，必须分别获得所有者批准。

未来获批准的本地处理可能涉及邮件标识、会话标识、接收与发现时间、邮件头，以及后续另行批准读取的内容；处理结果包括分类、英文草稿、独立中文译文、通知和审核状态、队列及同步检查点。

当前真实正文读取关闭。 Gmail 的正文响应可能包含内嵌附件，尚不能将“不主动下载附件”当作“没有接收附件内容”。有限读取的范围、总量及内容选项必须明确，不自动扩大。

03Google 用户数据与 Limited Use

Gmail AI Assistant 对从 Google API 获取的信息的使用及向其他应用的转移，将遵守 Google API Services User Data Policy（包括 Limited Use 要求），以及适用的 Google Workspace 用户数据与开发者政策。当前尚未接入真实 Gmail 或 AI 服务。

今后仅在本人明确授权后，按已披露的用途处理获准的 Google 用户数据及其派生内容。本应用不会出售这些数据，不会将其用于广告投放或定向广告，也不会将其用于、或允许受托服务将其用于创建、训练或改进面向其他用户的通用 AI 或机器学习模型。

启用外部服务前，将确认服务提供商、传输字段及数据使用规则符合上述限制，并更新相应隐私披露；未完成确认前，不向其传输真实邮件。此声明不表示已经通过 Google 验证或真实服务验收。

04本地存储与安全边界

本地存储后端使用 SQLCipher Community Edition 加密邮件相关数据库，包括草稿、译文、处理队列、通知记录、审核状态和同步检查点。已用合成数据验证加密库、WAL 数据页与加密备份；部分文件结构元数据和运行时内存不能等同于全字节加密或安全擦除。

凭据保护采用应用专用原生辅助程序和 macOS Keychain。刷新凭据与数据库密钥分开保存；当前实际测试只使用虚构凭据，生产规则与真实凭据启用保持分离。无法获取原密钥时停止，不创建替代密钥、不清空数据库、不重置检查点。

本地文件权限、代码身份和加密不能抵御所有同用户权限下的入侵、内存读取或系统失陷。真实备份的密钥恢复安排仍待批准；重新授权 Gmail 不能恢复丢失的数据库密钥。

06如何撤销授权

如果未来完成授权，所有者可在 Google 账号的第三方连接管理中找到本应用并移除访问权限，以撤销后续访问。应用内专用撤销入口尚未实现，本政策不宣称存在该功能。

撤销授权不会自动删除已经保存在 Mac、备份或曾获批准接收数据的外部服务中的副本。当前尚无真实 Gmail 用户授权可撤销。

07数据保留与删除

当前没有自动到期删除或一键删除功能，不默认开启真实数据自动备份。 首轮有限只读验证仍须另行批准邮箱、范围、整次总量及内容选项，并使用专用工作副本。本政策生效不构成真实 Gmail 授权或邮件读取许可。

首轮验证完成或终止时，立即停止使用该工作副本，列出本次工作副本及任何单独获准产生的备份，经所有者确认具体清单后再人工清理。未经清理确认不自动删除；没有自动到期删除期限，在确认并实际清理前，工作副本可继续保留在本机。

工作数据、备份和 Keychain 凭据分别核对。清理工作副本不自动删除 Gmail 原始邮件、刷新凭据或数据库密钥。凭据删除与授权撤销须分别确认；删除数据库密钥前，须确认没有仍需保留的加密数据或备份依赖该密钥。合成测试副本的清理不等于真实数据删除已经验收。

撤销 Gmail 访问权限与删除本地数据是不同操作。删除本地文件不代表废纸篓、系统快照、其他备份或外部服务副本同时消失，也不承诺 SSD 安全擦除。已经传输到第三方的数据还需按相应服务的规则处理。
